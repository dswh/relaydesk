Goal: make the test suite 20% faster

Start once with /goal. Replace the highlighted fields for your project.

Open slide 12
Goal

/goal Make the full test suite at least [20%] faster.

Trigger

Start when I submit this goal.

Action

Record the median of [3] full runs on the same runner.

Profile the slowest work. Change one shared cause.

Check + save

Rerun the same suite [3] times after each change.

Keep changes only when tests pass and timing improves.

Preserve every test, assertion, fixture, and coverage target.

Save timings, the diff, and the next idea in [loop-state.md].

Repeat + stop

Repeat until the [20%] improvement is verified.

Stop after [3 changes] or [25 minutes], or if blocked.

Leave a local diff for review. Do not merge or deploy.

Scheduled: keep docs in sync with shipped code

Claude Code /loop. Replace the highlighted fields before starting.

Open slide 13
Goal + interval

/loop [1h] Check shipped changes since [docs-loop-state.json].

Trigger

Run hourly while this session is open.

Action

List documentation that disagrees with those shipped changes.

Update one verified mismatch. Build docs and check links.

Check + save

Repeat within this pass until the list is empty.

If a docs diff awaits review, skip this pass.

Leave unclear product claims for a person to review.

Save the checked commit, remaining items, and test results.

Stop

Stop each pass after [3 edits] or [15 minutes].

If there is no work, make no edits. Do not publish.

Cancel this recurring task after [3 passes].

An alert: work through one error window

An alert supplies logs. An engineer starts /goal with the fixed export.

Open slide 14
Goal

/goal Resolve reproducible errors in [logs/error-window.json].

Trigger

Start after an alert supplies this fixed log export.

Action

Group duplicates. Select one high-impact reproducible group.

Reproduce it locally. Add a failing test. Fix one shared cause.

Check + save

Rerun that test and the full suite after each change.

Repeat for the remaining groups in this same log window.

Save the reproduction, diff, and test results.

Report external failures separately. Do not call them fixed.

Stop

Stop when all reproducible groups pass their tests.

Stop after [3 fixes] or [25 minutes], or on an unclear cause.

Leave a local diff. Do not change production or deploy.

Before starting a run

Use a prepared repository with the named tests, logs, or documentation checks. If a required input is missing, stop and report what is needed.

A goal continues toward a result. A scheduled task checks again later. The error example starts when an engineer hands off a fixed log export. The goal command alone does not subscribe to alerts.

The hourly example needs a saved checked commit and pass count. Keep the session open. Confirm cancellation after the third pass. Prompt instructions express limits. Use the runner or platform controls when a time or spending ceiling must be enforced.
