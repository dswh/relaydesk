How the seven workshop steps map to this run

Observe and protect

1. Sensor: actual retrieval query, document rank, source IDs, and LangSmith traces.
2. Regression protection: fixed questions, corpus, models, checks, and previously passing results.
3. Controller: select a failed development question and its shared failure family.

Change and review

4. Actuator: Codex applies one small change in a separate worktree.
5. Runner: product tests, repeated retrieval, and a frozen held-out comparison.
6. Human feedback: inspect the answer and patch, then record the engineering decision.
7. Flow control: one pending review blocks another model call.
