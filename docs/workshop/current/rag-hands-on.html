What fills each box in the control loop?

PartOur implementation
Desired stateEvery active question finds its expected approved article first. Product tests still pass.
ControllerThe failure selector gives one failed question and its evidence to the repair task.
ActuatorCodex and the repair skill make a small code change in an isolated worktree.
SystemThe RelayDesk retrieval and answer pipeline.
SensorSaved search queries, returned sources, repeated ranking checks, and product tests.
New inputA changed source or question set can start fresh checks after review.

The automatic goal in this exercise covers retrieval.

Answer quality has a separate review. A source-ranking pass does not prove a correct or complete answer.
